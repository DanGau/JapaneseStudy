# JapaneseStudy

Personal Android app for studying Japanese while travelling — flashcards, study material, and more. Built for one user (Dan); not intended for distribution.

## Planned scope
- Flashcards (kana, kanji, vocab) with spaced repetition
- Study material / reference notes
- Offline-first, since it's meant for use while travelling
